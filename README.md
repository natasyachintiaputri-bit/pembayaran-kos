# Aplikasi Pembayaran Kos Berbasis Web

## Deskripsi
Aplikasi Pembayaran Kos merupakan sistem informasi berbasis web yang dirancang untuk membantu pengelolaan pembayaran biaya kos, seperti listrik dan WiFi. Aplikasi ini memudahkan pemilik kos dalam mengelola data penghuni, membuat tagihan, memverifikasi pembayaran, serta melihat laporan pembayaran.

## Fitur Aplikasi

### 1. Admin / Pemilik Kos
- Login admin.
- Mengelola data penghuni (Tambah, Edit, Hapus).
- Mengelola tagihan pembayaran kos.
- Melihat data pembayaran penghuni.
- Memverifikasi pembayaran.
- Melihat laporan pembayaran.

### 2. Penghuni Kos
- Login penghuni.
- Melihat tagihan pembayaran.
- Melakukan pembayaran melalui metode Cash atau Transfer.
- Mengunggah bukti transfer.
- Melihat riwayat pembayaran.

## Teknologi yang Digunakan
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- phpMyAdmin

## Database
Aplikasi ini menggunakan MySQL sebagai sistem manajemen basis data dengan nama database `pembayaran_kos`.

## Cara Menjalankan Aplikasi

1. Install XAMPP.
2. Jalankan Apache dan MySQL.
3. Salin folder `pembayaran-kos` ke dalam folder `htdocs`.
4. Buka phpMyAdmin.
5. Buat database dengan nama `pembayaran_kos`.
6. Import file database SQL jika sudah tersedia.
7. Sesuaikan konfigurasi database pada aplikasi.
8. Buka browser dan akses:

   `http://localhost/pembayaran-kos/`
